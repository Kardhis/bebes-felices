# Investigación de productos para categorías educativas

Revisión editorial realizada el 18 de agosto de 2026. Las 14 colecciones de
`/juguetes-educativos/` muestran seis productos cada una. Cada ASIN se ha
comprobado con una ficha viva en Amazon España (HTTP 200 y título coincidente).
Estas fuentes no acreditan resultados clínicos ni garantizan disponibilidad
continua.

Los enlaces publicados son `https://www.amazon.es/dp/{ASIN}` y, si hay etiqueta
de afiliado configurada, incluyen `?tag=`.

## Criterios de publicación

- Cada ASIN del catálogo educativo es único: si dos páginas muestran el mismo
  producto, reutilizan el mismo identificador interno.
- La edad principal de la colección debe estar incluida en el rango indicado
  por la fuente.
- La inclusión es editorial, no un ranking ni una afirmación de eficacia.
- El botón de Amazon solo se publica cuando el catálogo enriquecido valida un
  ASIN de diez caracteres y genera una URL HTTPS hacia `www.amazon.es`.
